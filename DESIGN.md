# COCM Internal — Brand Tokens

Shared with the COCM Bookshop red/blue visual identity.

- **COCM red** `#e5444c` — actions / CTAs (buttons, destructive accents)
- **Deep blue** `#2d2f92` — navigation, headings, structure
- **Paper white** `#faf7f0` — page backgrounds
- Principle: **blue handles structure; red handles action**

## Tailwind tokens (`cocm` key)

| Token | Value | Use |
|---|---|---|
| `cocm-paper` | `#faf7f0` | page background |
| `cocm-ink` | `#2d2f92` | headings, nav, primary text |
| `cocm-ink-light` | `#4a4dc0` | hover states on blue |
| `cocm-ink-pale` / `cocm-blue-pale` / `cocm-sky` | `#e4e5fb` | pale blue tints |
| `cocm-red` | `#e5444c` | primary buttons, actions |
| `cocm-red-dark` | `#c9333b` | button hover |
| `cocm-red-light` | `#fbe0e1` | error/info tints |
| `cocm-slate` | `#5d5f7d` | secondary text |
| `cocm-sand` | `#f5efdc` | warm accent surfaces |

Typography: DM Serif Display for headings, Inter for body.
Radii: `rounded-card` (20px), `rounded-panel` (28px).
Shadows: `shadow-card`, `shadow-panel`, `shadow-red-glow` (neutral-tinted).
